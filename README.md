# Java Lotto Precourse

## 1️⃣ 입력 기능
- [x] 로또 구입 금액 입력
- [x] 당첨 번호 입력
- [x] 보너스 번호 입력

---

## 2️⃣ 입력 검증

**공통 요구사항**  
- [ ] 입력값 예외 발생 시, 올바른 입력이 들어올 때까지 다시 입력받기

### 1. 로또 구입 금액 검증
- [ ] 숫자가 아닌 경우 예외 처리  
- [ ] 숫자인 경우 1,000으로 나누어 떨어지지 않으면 예외 처리  

### 2. 로또 당첨 번호 검증
- [ ] 문자열이 숫자와 `,` 로만 이루어져 있지 않으면 예외 처리  
- [ ] `,` 기준으로 분리했을 때 숫자가 6개가 아니면 예외 처리  
- [ ] 숫자 중 1~45 범위를 벗어나면 예외 처리  

### 3. 보너스 번호 검증
- [ ] 숫자가 아닌 경우 예외 처리  
- [ ] 숫자인 경우 1~45 범위를 벗어나면 예외 처리  

---

## 3️⃣ 로또 구입 기능
- [ ] 중복 없는 무작위 6개의 번호 생성  
- [ ] 구입 금액 ÷ 1,000 만큼 로또 생성  

---

## 4️⃣ 당첨 통계
- [ ] 구입한 각 로또와 당첨 번호를 비교하여 일치한 숫자 개수 계산 
- [ ] 일치 개수 및 보너스 번호 일치 여부에 따라 당첨 금액 결정  
- [ ] 각 등수별 당첨 개수 집계
- [ ] 전체 수익률 계산

---

## 5️⃣ 출력 기능 (LottoView)
- [ ] 구입 금액 입력 후 구입 개수 출력
- [ ] 구입한 로또 번호 목록 출력
- [ ] 당첨 통계 결과 출력
